# MDNote

A music director note, shown under a section title, for the whole band or for specific instruments.

- **For everyone:** the word **MD** in `md`, bold, then the note in `ink`, style `note`.
- **For one or more instruments:** an InstrumentTag per instrument, then the note.
- **Plain notes** (a `>` line without MD) use `ink-muted` and no label.
- Order inside a section: everyone's notes first, then instrument notes.
- In a player's view, show only notes for everyone plus that player's instruments. The MD sees all, each with its tag.
- Never style a note with a colored left border or a colored box: the label carries the meaning.
