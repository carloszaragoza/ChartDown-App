How it works

  1. 1

    Write it in ChartDown

    Plain text that reads like a chart: sections, bars, numbers, and notes for each instrument.

  2. 2

    Build your set

    Pick the versions you play, set the key for each song and assign every musician an instrument.

  3. 3

    Play from your part

    Everyone sees the same song. Each player sees the cues meant for them.

Built for the stage

  • Offline sets

    Download a set before you leave. Every chart opens in airplane mode.

  • Atril mode

    Full screen, big numbers, one tap to the next section.

  • Your part only

    Each musician sees the MD notes for their own instrument.

  • Every change saved

    Go back to any revision. Sets stay on the version you chose.

ChartDown is an open language

The notation is public domain (CC0) and lives on GitHub. Write your charts once, keep them as plain text forever, and use them in any app that supports ChartDown.
