ChartDown 0.4 visual reference

Every part of the language, drawn

Each example shows the ChartDown text on the left and how a renderer draws it on the right. Under every bar, one slash marks each beat, so you can see exactly how long each chord lasts.

/ one beat: strong, semi-strong, weakdashed line = chord change inside a bar◇ around a chord = hold, let it ring
