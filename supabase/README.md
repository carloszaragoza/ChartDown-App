# supabase

Postgres schema, row-level security policies and server functions for ChartDown App (Technical Plan 3 and 4).

- `migrations/`: schema and row-level security, with SQL tests (from T-301 and T-304).
- `functions/`: server functions such as the per-instrument view and the offline bundle (from T-801).

The Supabase projects and CLI configuration are set up in T-003.
